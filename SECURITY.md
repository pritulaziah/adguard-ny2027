# Security policy

## Supported versions

The published site follows `main`. Only the current `main` branch
receives fixes.

## Report a vulnerability

Do not open a public issue for a security problem.

Use GitHub private vulnerability reporting:

1. Open the repository on GitHub.
2. Select the **Security** tab.
3. Select **Report a vulnerability**.
4. Describe the problem, the steps to reproduce it, and the possible
   impact.

The maintainer reads the report and answers in the advisory. Add no
secrets or personal data to a public issue or a pull request.

## Scope

The project is a static site. It has no server, no accounts, and no
data collection. A report is in scope when it concerns:

- the published page at
  https://pritulaziah.github.io/adguard-ny2027/;
- a link that the page opens;
- the GitHub Actions workflows in `.github/workflows/`.

A problem in AdGuard products or in the AdGuard website is out of
scope. Report it to AdGuard support.
